# ojithreew — Minimal Snow Portfolio

Portfolio React + Vite 5 tanpa foto, Article, MDX, atau asset media. Tampilan text-first dengan background putih reflektif, warna tipografi, dan animasi salju ringan.

## Jalankan di Termux

```bash
npm install
npm run dev
```

## Build produksi

```bash
npm run build
npm run check
```
